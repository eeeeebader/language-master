# @lm/site

Astro marketing site (`src/`) and VitePress docs (`docs/`, served under `/docs/`).

- `pnpm dev` (site) / `pnpm docs:dev` (docs)
- `pnpm build` writes `dist/` (site) and `dist/docs/` (docs)

Legal drafts in `src/content/*.md` are copies of the client's texts; the FAQ comes from the plan's
learning guide.
